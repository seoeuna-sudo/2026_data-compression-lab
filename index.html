압축 연구실 — 원본에서 압축본까지

원본 데이터가 주어지면, 런-렝스 압축과 허프만 압축 과정을 단계별로 아주 자세하게 따라가며 직접 계산해서 압축된 데이터를 완성해 보자. 문제는 버튼을 누를 때마다 새로 만들어져.

🔁 런-렝스 압축

① 원본 문자열 확인하기

런-렝스(Run-length) 압축은 동일한 문자가 연속해서 반복될 때 그 문자와 반복 횟수를 번갈아 적어서 압축하는 방법이야.

예시로 감 잡기 — 원본 aaabbccccc (10글자)를 압축하면?
  1. 같은 문자가 이어지는 구간(런, run)을 나눈다 → aaa / bb / ccccc
  2. 각 구간을 "문자+반복 횟수"로 바꾼다 → a3 / b2 / c5
  3. 이어 붙이면 압축 결과 a3b2c5 (6글자) 완성!
-

② 반복 구간(런) 나눠 보기

먼저 원본 문자열에서 같은 문자가 몇 번씩 연속되는지 눈으로 나눠 보자. 아래 버튼을 눌러 힌트를 확인할 수 있어.

반복 구간 나누기 힌트 보기 / 숨기기

③ 압축 결과 입력하기

각 구간을 "문자+반복 횟수" 형태로 바꾸고, 순서대로 이어 붙여서 압축된 문자열을 완성해 봐. 비트 수는 압축된 문자열의 글자 수에 8을 곱하면 돼 (문자 1개 = 8비트).

힌트 보기
원본 비트 수압축 후 비트 수
-

압축률 = (원본 데이터 크기 − 압축된 데이터 크기) ÷ 원본 데이터 크기 × 100(%) — 값이 클수록 용량을 더 많이 줄였다는 뜻이야.

* 본 연습 도구는 영문 알파벳 1글자를 ASCII 코드 기준 8비트(1Byte)로 계산합니다.

🌳 허프만 압축

① 원본 문자열 확인하기

허프만(Huffman) 압축은 자주 나오는 문자에는 짧은 코드를, 드물게 나오는 문자에는 긴 코드를 부여해서 전체 크기를 줄이는 방법이야. 6단계를 순서대로 풀며 압축 코드를 완성하고 복원까지 해 보자.

⚖️ 동률(빈도수가 같을 때) 처리 규칙 — 빈도수가 같은 노드가 여러 개면 ①이미 결합되어 만들어진 노드를 먼저 결합하고, 그다음 ②알파벳순으로 결합해. 그리고 트리에서 코드를 읽을 때는 왼쪽 가지 = 0, 오른쪽 가지 = 1로 약속해. 이 규칙을 지켜야 교과서와 똑같은 트리 모양이 나와!
진행 순서 미리 보기
  1. 문자별 빈도수 세기
  2. 빈도수 순으로 노드 정렬하기
  3. 가장 작은 두 노드부터 차례로 결합해 이진트리 만들기
  4. 완성된 트리에서 이진 코드 읽어내기 (왼쪽 0, 오른쪽 1)
  5. 원본 문자열 전체를 코드로 바꿔 압축률 확인하기
  6. 압축된 비트열을 거꾸로 문자로 복원해 보기 (디코딩)
-

* 본 연습 도구는 영문 알파벳 1글자를 ASCII 코드 기준 8비트(1Byte)로 계산합니다.
